# pc-builder-guide - Project Documentation

# Project Specification Summary
A website designed to simplify the PC building process for gamers. It offers guided recommendations (Budget/Quality paths) based on user needs and a "Build Labs" feature for manual configuration and performance estimation. The core goal is to provide accurate performance predictions based on real-world benchmark data.

# Architecture Summary
Monolithic backend API serving data and logic to a React frontend. PostgreSQL database stores component specs, compatibility rules, and benchmark data. Python scripts used offline during development to scrape and populate the database. Initial focus on backend data structures, scraping strategy, and the core estimation engine logic (v0.1).

DB Schema:
Our database schema is designed to store PC components and benchmark data:

1. **Cpu Model**:
   - cpuId (PK)
   - modelName (unique)
   - manufacturer
   - coreCount
   - threadCount
   - baseClockGhz
   - boostClockGhz
   - socket
   - timestamps

2. **Gpu Model**:
   - gpuId (PK)
   - modelName (unique)
   - manufacturer
   - memoryGb
   - memoryType
   - timestamps

3. **Game**:
   - gameId (PK)
   - title (unique)
   - releaseYear
   - timestamps

4. **Benchmark** (Core Table):
   - benchmarkId (PK)
   - cpuId (FK, optional)
   - gpuId (FK, required)
   - gameId (FK, required)
   - resolution
   - graphicsSettings
   - averageFps
   - minimumFps
   - percentile1Fps
   - dataSourceUrl
   - scrapedAt
   - uniqueness constraint across multiple fields

API Endpoints:
The following API endpoints have been implemented:

1. `GET /api/v1/health` - Health check endpoint, returns server status and timestamp
2. `GET /api/v1/components/cpus` - Retrieves all CPUs from the database
3. `GET /api/v1/components/gpus` - Retrieves all GPUs from the database
